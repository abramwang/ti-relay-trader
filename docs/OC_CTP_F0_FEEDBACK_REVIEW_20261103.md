## 2. 接受并修订的边界

| 项目 | Relay 处理 |
| --- | --- |
| 合约查询 | InstrumentField 只提供相应静态事实；IsTrading 不证明账户权限或当前订单必能接受，也没有动态涨跌停价。合约查询成功不单独放行新单 |
| 合约日期 | 登录 TradingDay 是查询请求上下文，不写成 InstrumentField 自带字段；保留来源、采集时间和有效性 |
| 持仓维度 | 明确返回的空 InvestUnitID 可规范为 `""`；缺失/解析失败不等于空串，不能落成一条看似完整的持仓 |
| 资金范围 | 增加 BizType 及 TradingDay/SettlementID 的原始保留；不同账户、币种、BizType 不合并，AccountID 不由 InvestorID 拼后缀 |
| 原生编号 | 接受 `native_ids` 作为待冻结的结构方向；字符串编号与数值会话/request ID 分列，华鑫数值 order_id 不改成混合字符串类型 |
| 字符字段 | 定长空间填充、前导零、大小写的规范化必须有逐字节样例；raw 与用于唯一键的规范值分离，不能两端各自 trim |
| 未关联成交 | 持久暂存并查询补齐，保留采集证据和待关联状态；不得捏造委托价/原始委托量绕过订单外键 |
| 撤单准入 | 新单与撤单可分别判定，但 trading_enabled=false 仍然禁止交易写入，包括撤单；不能借独立撤单门禁绕过只读授权 |
| 日期和恢复 | TradingDay 与自然日期分离，源日期缺失不猜测；幂等重投恢复原意图，未知结果不重报，SDK 与 Redis 不是原子事务 |

将“新单关闭但允许撤单”作为后续显式配置与心跳契约设计，不暗中改变现有权限开关。OC 目前仍共用 canTrade、快照未就绪，不能宣称已经具备独立撤单能力。
