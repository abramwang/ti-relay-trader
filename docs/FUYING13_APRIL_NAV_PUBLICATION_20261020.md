## 计算政策

```text
资产 = 券商现金 + 实际未到期逆回购本金
盈亏 = 当日期末资产 - 前日期末资产 - 银证净流入 - 债券策略资本净流入
日收益率 = 盈亏 / 前日期末资产
单位净值 = 前日单位净值 × (1 + 日收益率)
```

4月1日单位净值为1，仅为观察锚点；当日盈亏及日收益未知，以质量标记明确，不据此推算3月末资产。首行数据库数值0为锚点展示占位，不是已经证明首日无收益。

债券买卖的实际净收付均作为子组合与另一策略之间的资本流，不计作产品盈利，不冒充全账户新增银证转账。`external_net_flow` 只保存真实银证流，`pnl_components.strategy_capital_net_flow` 单列策略资本流，`funding_net_flow` 为二者之和。债券原始委托零点时间与现金晚间记账时间不被补造成经济划转时刻；日末净流量只是明确的日度计量约定。
