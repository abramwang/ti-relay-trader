# relay 开发路线图

更新时间：`2026-11-05`

## 状态口径

- `done`: 已完成并提交。
- `doing`: 当前优先推进。
- `todo`: 已规划，尚未开始。
- `blocked`: 受外部信息、权限或环境阻塞。
- `deferred`: 已明确暂缓，不纳入近期 relay 边界。
